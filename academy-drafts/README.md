# Academy article drafts

Ready-to-import Academy articles, staged here as JSON files (matching the
schema used by `/admin/academy/upload`) so an admin can review and publish
them without writing SQL by hand.

## How to publish one

1. Sign in as an admin and go to `/admin/academy/upload`.
2. Paste or upload the JSON file's contents.
3. Review the rendered preview, then save.

Articles live in the database once published — these files are just staging
drafts and aren't read by the app at runtime.

## Files

- `beyond-seo-social-media-video-traffic-strategy.json` — a guide for
  creators on using TikTok, Instagram, YouTube, and Facebook short-form
  video (with tools like CapCut and Leonardo) as a traffic channel alongside
  SEO articles.
