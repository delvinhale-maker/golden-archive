# Rights Passport — Launch Readiness Matrix

Compiled as part of the release-candidate master pass on
`rights-passport/foundation`. Statuses: **PASS** / **PARTIAL** / **BLOCKED**
/ **NOT IMPLEMENTED**. Every PASS cites concrete file/test evidence — no
score here is asserted without a pointer to the code or test that backs it.
