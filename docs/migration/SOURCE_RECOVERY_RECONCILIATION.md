## Intentional/non-secret exclusions

### 1. Lovable-bound Wallet scheduler migration — QUARANTINED

`supabase/migrations/20260902213142_f8dffe65-c985-4f29-ba77-80405c3dd48b.sql` is intentionally not restored for execution on the independent stack. The original migration hard-codes a Lovable-hosted endpoint and embeds a project credential in the scheduled request. Re-introducing it would recreate the platform dependency being removed and would risk committing a credential to Git.

The business schema migrations before and after it are retained. A replacement scheduler migration must be written only after the independent endpoint/secret contract is defined.

### 2. Environment file change — NOT COPIED

The final Lovable edit includes only a newline change to `.env`. Environment values and credentials are not copied into Git as part of recovery. Independent staging/runtime environment variables will be configured out-of-band.
